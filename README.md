## sobre mim

Oi, eu sou o Luiz Manoel 👋

Estudo Análise e Desenvolvimento de Sistemas na UNINOVE (estou no 2º semestre, com formatura prevista para 2028) e moro em São Paulo.

Gosto de pegar uma ideia e fazer ela funcionar de verdade. Foi assim com o **LoveTime**, uma aplicação web que criei do zero para casais registrarem suas histórias e memórias, e que hoje está publicada no GitHub Pages.

Trabalho no setor de e-commerce de um supermercado, e foi ali que aprendi a manter a rotina organizada, ter responsabilidade com prazo e trabalhar em equipe. Agora quero levar isso para a área de TI.

**aplicação web personalizável para casais** · projeto pessoal

Um site para registrar histórias e memórias de um casal, com tudo reunido em um só lugar:

- galeria de fotos
- linha do tempo de memórias

Feito com HTML5, CSS3 e JavaScript, responsivo e publicado via GitHub Pages.

`HTML5` `CSS3` `JavaScript` `Git` `GitHub Pages` `Responsive Design`
